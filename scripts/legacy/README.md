# Chuyển schema lịch sử

Các script ở đây chỉ dành cho database cũ/bản sao phục hồi đã kiểm tra. SQL nguồn
nằm ở `archive/database/`. Không thuộc quy trình cài mới hoặc chạy ứng dụng hiện tại.

Database hiện tại dùng duy nhất `src/main/resources/db/migration/V*.sql` qua
`DatabaseMigrations` / `scripts/Install-Database.ps1`.
