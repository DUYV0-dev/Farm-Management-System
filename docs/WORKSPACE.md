# Hướng dẫn hiện hành

Tài liệu này đã được hợp nhất vào [RUNBOOK](RUNBOOK.md) và [ARCHITECTURE](ARCHITECTURE.md).
Run IntelliJ giữ giao diện hiện tại; production dùng JAR đã kiểm chứng; dữ liệu ở PostgreSQL.

Bản hướng dẫn cũ được giữ ở [archive/docs](../archive/docs/). Không áp dụng lệnh SQL/script
lịch sử vào database hiện hành. Migration chuẩn nằm ở src/main/resources/db/migration.
